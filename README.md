## 💼 Ключевые проекты

### 🧾 Сканер чеков с разделением расходов
**Стек:** `Python` `JavaScript` `HTML`
> Командная разработка веб-приложения для парсинга товарных чеков и автоматического расчета долей каждого участника.
- Реализован бэкенд на Python для обработки данных.
- Разработан фронтенд на JavaScript и HTML для интуитивного взаимодействия.

### 🖥 Аналоги Linux утилит (cat, grep)
**Стек:** `C`
> Индивидуальная реализация базового функционала стандартных системных утилит с нуля.
- Глубже понимание работы низкоуровневых операций в UNIX-подобных системах.

### 📚 Самописные библиотеки (string.h, decimal)
**Стек:** `C` `Командная работа`
> Разработка с нуля библиотек для работы со строками и числами с плавающей точкой с соблюдением стандартов.
- Отработка навыков написания чистого, эффективного и тестируемого кода.
- Опыт коллективной разработки и проведения код-ревью.

### 🎨 Генератор фракталов Жюлиа
**Стек:** `Python` `NumPy` `Qt5`
> Desktop-приложение для визуализации и исследования множества Жюлиа с динамическим изменением параметров.
- Использование NumPy для эффективных вычислений.
- Реализация параллельных вычислений для ускорения рендеринга.
- Создание графического интерфейса на Qt5.

### ∫ Приложение для математических расчетов
**Стек:** `Python` `Qt5` `Numba`
> Разработка приложения для решения сложных математических задач: вычисление интегралов, решение дифференциальных уравнений и поиск корней.
- Интеграция JIT-компиляции через Numba для значительного ускорения расчетов.
- Создание удобного GUI для ввода данных и визуализации результатов.
